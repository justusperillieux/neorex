The primary logo is `neorex-logo-mascot.png`: a complete Rex dinosaur holding
the Neovim emblem on Rex's gradient badge. Its saved prompt records the
character and background steps. The mascot follows the Plugin Rex visual style.

The earlier geometric mark is kept as `neorex-logo.svg`, with transparent
negative space and flat blue/green fills. `neorex-logo-transparent.png` is its
2048 × 2048 export:

```sh
rsvg-convert --width 2048 --height 2048 --output assets/neorex-logo-transparent.png assets/neorex-logo.svg
```

`neorex-logo-n-rex.png` and its saved prompt preserve the approved visual
reference used to trace the vector mark.
